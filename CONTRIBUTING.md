# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bugs and ideas:** open an issue and pick Bug report or Idea. A short video helps a lot: pause the game, choose RECORD, and attach the saved video.
- **Pull requests:** keep each one to one change, run `npm test`, and try the game in the browser (see Development in the README). The pull request form asks you to accept the [Contributor License Agreement](CLA.md).
- **License:** SLAMLINE is source-available under the [PolyForm Noncommercial License](LICENSE.md): you may play, read, change and share it for free, but not sell it or use it commercially. The SLAMLINE name and logo aren't licensed, so a copy you publish needs another name.
